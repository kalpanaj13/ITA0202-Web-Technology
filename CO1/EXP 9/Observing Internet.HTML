🌐 Observing Internet Protocols

Using Browser Developer Tools Network Tab

Steps to Observe Network Activity

  • Open your browser (Chrome, Edge, or Firefox).
  • Press F12 or right-click → Inspect to open Developer Tools.
  • Go to the Network tab.
  • Reload the webpage to capture network requests.
  • Observe details like URL, Protocol, Request Method, Status Code, File Type, Size, and Loading Time.

Common Protocols

HTTP
HyperText Transfer Protocol
Used for web communication.
HTTPS
Secure version of HTTP
Encrypts data for safety.
FTP
File Transfer Protocol
Transfers files between client and server.
DNS
Domain Name System
Converts domain names to IP addresses.

Observation Example

When you load a webpage, your browser sends a GET request to the server using HTTPS. The server responds with a Status Code 200 (OK) and returns files like HTML, CSS, JavaScript, and images. You can view file size, type, and loading time in the Network tab.
